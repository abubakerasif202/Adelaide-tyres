## 1. Greforce G-ARMOR

CURRENT LISTING
- Brand: Greforce
- Pattern: G-ARMOR
- Size: 11R22.5
- Current application: truck, all-position, "heavy duty"

VERIFICATION RESULT: **Unverified**

OFFICIAL PRODUCT
- Brand: Greforce = Shandong Greforce Tire Co. / Shandong Kaixuan Tire Co. (ex-"Grenlander")
- Pattern: no pattern named "G-ARMOR" (or "G-ARMOUR") could be found on the
  manufacturer site or any distributor.
- Greforce **does** use a "G-" family name — "G-PILOT" — with sub-models
  X1 (steer), X3 (drive), X5 (light-truck drive/trailer). So a parallel
  "G-ARMOR" family is *plausible* (it would fit a mixed-service / on-off-road
  pattern) but nothing corroborates it.
- Checked: greforcetire.com product list, pages /563–/572, the G-PILOT X1
  "related products" block, made-in-china Kaixuan store, chinesetrucktire.com,
  budgettrucktires, prioritytire, tiremart. No hit.
- Greforce's verified 11R22.5 patterns: GR612, GR622, GR636, GR661, GR662,
  GR678, GR775, GR776, GR881, GRD37, GRD1212, GRD1818, GR1919, LWD57, LWD02,
  LWD97, LWD98, GRD57. None is "G-ARMOR".

## 3. Jumbo SS618

- Brand: Jumbo
- Pattern: SS618
- Size: 275/70R22.5
- Current application: commercial, drive, "low-profile drive tyre … urban distribution"

VERIFICATION RESULT: **Unverified**

OFFICIAL PRODUCT
- Brand: "Jumbo" TBR tyres are a brand of **Qingdao Grandstone Tyre Corporation
  Ltd** (they sell GRANDSTONE and JUMBO). Also retailed in Australia via
  roadtread.com.au.
- The Jumbo **SS-series is real**: verified patterns include SS200 (12.00R24
  drive), SS366 (12R22.5 drive), SS580 (315/80R22.5 all-position),
  SS668 (11R22.5 drive, traction block).

  Alibaba, or any distributor.
- SS668 is the closest by number (also a drive tyre) but it is 11R22.5 with a
  block traction pattern — a *different* size and pattern. **Not** substituted.
- 275/70R22.5 is a real Grandstone size (they list a 275/70R22.5 all-steel
  radial) but no SS-series code was tied to it.

## 4. Ralson RAC55  →  INCORRECT (do not rewrite without the physical tyre)

CURRENT LISTING
- Brand: Ralson
- Pattern: RAC55
- Size: 295/80R22.5
- Current application: truck, **steer**, "steer-axle radial with **rib tread** for
  stable tracking and long, even front-axle wear on highway work"

VERIFICATION RESULT: **Incorrect** (for RAC55). The current size does not exist and
the current position + tread description do not match the real RAC55.

OFFICIAL PRODUCT
- Brand: Ralson Tire (Ralson Tire North America)
- Pattern: **RAC55** — real, current product (launched as a TBR line).
- Verified sizes: **315/80R22.5, 11R22.5, 11R24.5, 385/65R22.5, 425/65R22.5**.
  **295/80R22.5 is NOT offered.**
- Application: **Construction / waste haul**, on/off road.
- Position: **All-position** (open shoulder), NOT steer-specific.
- Tread: deep **24/32"** open-shoulder **block** pattern with tie bars, notches
  and stone ejectors — an aggressive mixed-service tread, the opposite of a
  highway steer rib.
- Ralson's actual 295/80R22.5 **steer / rib** tyre is the **RMR61** — which is
  already a separate SKU in this catalogue (and now has its real photo).
- Ralson TBR family for reference: RMR__/RSR__ = steer, RDR__/RDC__ = drive,
  RTR__ = trailer, RAC__ = all-position/construction.

SOURCES
- https://ralsontires.com/tires/rac55/  (official — 5 sizes, all-position,
  construction/waste, 24/32 tread)
- https://ralsontires.com/wp-content/uploads/2025/04/Ralson-RAC55-Flyer-1.pdf
- https://www.moderntiredealer.com/industry-news/products/product/55056616/ (RAC55 launch)
- https://www.fleetmaintenance.com/equipment/brakes-tire-and-wheel/product/55135803/
- https://simpletire.com/brands/ralson-tires/rac55
- https://ralsontires.com/tires2/rmr61/  (RMR61 — the real 295/80R22.5 steer rib)

RECOMMENDATION: **Needs physical stock confirmation before any correction.**
The stock could be:
  (a) genuinely RAC55, in which case the catalogue size (295/80R22.5) and the
      "steer rib" description are both wrong — it should be one of the 5 real
      sizes and described as an all-position construction block tyre; or
  (b) a different Ralson pattern that was mis-coded as "RAC55" — e.g. if the
      tyre really is 295/80R22.5 steer rib, it is almost certainly **RMR61**
      (a duplicate of the existing SKU) or an RSR-series steer pattern.

Take a photo of an actual tyre from this stock line showing:
- sidewall brand ("RALSON")
- the pattern code moulded on the sidewall (RAC55? RMR61? RSR__?)
- the size marking and load index
- straight-on tread face (aggressive open-shoulder block = RAC55;
  fine highway ribs = a steer pattern)

Until then, leave the SKU untouched but treat its photo slot as "do not fill".
